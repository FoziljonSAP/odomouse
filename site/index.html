Your week on one card

Odomouse draws a card with your week: how far the cursor went, keys, clicks and your fastest typing. Save it as a picture or copy it straight into Telegram.

It counts keys. It does not read what you type.

Odomouse notes which key was pressed so it can count it and colour the heatmap. It never stores text, passwords or screenshots.

There is no account, no advertising and nothing is sent anywhere: all the numbers sit in one file on your computer, and you can export or delete them in Settings.

The code is open under the GPL-3.0 licence, so anyone can check this.

Opening it for the first time

The app is not signed with a paid Apple or Microsoft certificate yet, so the system asks once whether you trust it.

  1. Run Odomouse-Setup.exe and click Install. No administrator password is needed.
  2. If you see "Windows protected your PC", click More info, then Run anyway.
  3. The mouse icon appears by the clock, often inside the ^ menu. Drag it onto the taskbar to keep the counter in sight.
  1. Open Odomouse.dmg and drag Odomouse into the Applications folder.
  2. Open it from Applications. If macOS says it could not verify the app, go to System Settings, Privacy & Security, and click Open Anyway.
  3. To count keys, allow Input Monitoring: right-click the icon in the menu bar and choose "Allow keyboard access".
  1. Double-click odomouse_amd64.deb, or run: sudo apt install ./odomouse_amd64.deb
  2. Open Odomouse from the app menu. It needs Ubuntu 22.04, Linux Mint 21, Debian 12 or newer.
  3. On Wayland, run once: sudo usermod -aG input $USER, then log out and back in.
